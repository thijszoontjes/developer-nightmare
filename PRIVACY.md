# Privacy

Developer Nightmare does not collect, store, or transmit browsing data.

When the user clicks the extension, it uses the active tab permission to temporarily apply CSS to visible page elements. The script checks element dimensions locally to avoid changing hidden or zero-sized elements. Refreshing the page removes the effect.

The popup may show a tip link and a labelled sponsor card when configured by the publisher. Those links open only after the user clicks them. This extension does not load third-party advertising scripts or inject ads into webpages.
